## Common Themes

### 1. Testing Framework Improvements

Testing is the single most pervasive pain point across the entire Temporal ecosystem. Every SDK reports test framework issues, with the Go SDK (47 open test issues), Java SDK (37+ test server issues), and TypeScript SDK (12 testing issues) carrying the largest backlogs. Recurring problems include time-skipping failures with child workflows, panics and goroutine leaks in test environments, missing test server capabilities, and poor CI integration (Jest open handles, test flakes). The Features repository's top request for unit testing workflow versioning ([#649](https://github.com/temporalio/features/issues/649), 14 upvotes) reflects a gap that affects all SDKs.
